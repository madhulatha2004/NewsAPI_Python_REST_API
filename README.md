# Python News Project
This project is a simple Python application that fetcheas and displays the latest news articles using a public News API. It is designed to help users stay updated with current news.

# Features
- Fetch news using:
    * Everything API
    * Top Headlines API
- Choose from three output types:
    * Console display
    * Text file
    * CSV file
- Supports configuration using .ini or .yaml files
- Filter news by category
- Error handling for API failures and invalid inputs

# Requirements
- Python
- requests, tabulate, pyYAML
